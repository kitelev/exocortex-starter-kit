# Project child-tasks layout (MVG example)

Declarative body layout for `ems__Project` notes — adds a
`Child tasks` backlinks table with `label` + `Effort Status` columns **above**
the default Asset Relations section (`coexistsWithDefault: true` keeps the
legacy rendering intact while the new block renders alongside).

See `packages/obsidian-plugin/docs/EXO_LAYOUT.md` in the plugin repo for the
full block reference, priority ladder, and feature-flag details.

Copy-adapt this file — and the `Child tasks backlinks` block it references —
when declaring your own class-level layout; swap
`exo__Layout_targetClass` to the class you own and point
`exo__Layout_blocks` at the block assets you want rendered, in order.
