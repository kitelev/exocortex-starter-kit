# Child tasks backlinks (MVG example)

`exo__BacklinksTableBlock` referenced by the MVG
`Project child-tasks layout`. Filters UniversalLayout backlinks to
`ems__Task` rows that reference the open `ems__Project` through
`ems__Effort_parent`, and renders them as a table with two columns:
task label and current status.

Adapt by editing:

- `exo__BacklinksTableBlock_rowClass` — which class of backlinks to
  include.
- `exo__BacklinksTableBlock_referencingProperty` — which frontmatter
  property must reference the open note (drops rows whose backlink comes
  from a different property).
- `exo__BacklinksTableBlock_columns` — the column set, in render order.

See `packages/obsidian-plugin/docs/EXO_LAYOUT.md` in the plugin repo for
the full block schema and troubleshooting notes.
