# Task ← Project column set (MVG example)

Declarative UI configuration for UniversalLayout — when a `ems__Project` is
open, the auto-backlinks table groups its child `ems__Task` rows (via
`ems__Effort_parent`) and renders them with two columns: created-at and
label.

The resolver picks this set via **Tier 1** (exact match of both the row
class and the referencing property). See
`packages/obsidian-plugin/docs/RELATION_COLUMN_SET.md` in the plugin repo
for the full priority ladder and coexistence rules with `exo__TableLayout`.

Copy-adapt this file when declaring your own `(row-class, referencing-property)`
column set — swap the two wikilinks in `ui__RelationColumnSet_targetClass`
and `ui__RelationColumnSet_referencingProperty`, then reorder the columns
array to taste.
