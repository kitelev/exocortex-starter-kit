# exocmd__Command_targetClass

ObjectProperty introduced under RFC-CI-Tests v2 Phase 1 (Option C migration, 2026-04-20).

- **Domain**: `exocmd__Command` (`790e5b16-251d-4556-96ac-e5c7f1429b2e`)
- **Range**: any class (typically `ems__*`, `pn__*`)
- **Cardinality**: 0..1 (optional, single-valued)
- **Purpose**: surface the canonical host class for a Command so CI test harness `extractTargetClassFromCommand(cmd)` Strategy 1 can short-circuit ladder traversal.
- **Relationship to `exocmd__CommandBinding_targetClass`**: `Command_targetClass` is the *primary* host (test fixture instantiated as this class); `CommandBinding_targetClass` enumerates *all* hosts where the command is rendered. They MAY overlap; `Command_targetClass` is opt-in and never required.
