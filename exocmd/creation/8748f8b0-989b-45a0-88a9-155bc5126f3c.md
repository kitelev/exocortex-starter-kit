# Create project

Grounding action that calls the `createAsset` service to create a new `ems__Project`.

Uses the `service_call` grounding type with `inputSchema` to collect the project label from the user,
and `targetValue` to specify the prototype UUID (`ems__ProjectPrototype` at
`b2a49bb7-3a0f-4984-aa18-38832dc967bc`).

**Note**: the `ServiceRegistryPopulator` `createAsset` handler expects
`userInput.prototypeUID` (a UUID string), not the symbolic `prototype: "ems__ProjectPrototype"`
form. This grounding was historically authored with the symbolic key and silently
failed with `createAsset requires userInput.prototypeUID` whenever the `Create Project`
button was clicked — the fix here uses the canonical UUID form that matches sibling
groundings (`95aaab51-…` Create Area, `a222094b-…` Create Child Task, `c84e2e08-…`
Create Note).
