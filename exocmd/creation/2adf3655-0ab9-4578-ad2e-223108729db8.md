# Create Child Task

Creates a new task as a child of the current Project or Area by calling the `createRelatedTask` service.

- **Grounding**: Reuses `4919afb1-…` (`createRelatedTask`) — same service used by the Task→Task `Create Related Task` command.
- **Icon**: git-fork (matches `Create Related Task` visual convention)
- **Category**: creation
- **Input**: Task label (text field, from grounding input schema)
- **Bindings**: `ems__Project` and `ems__Area` (see `d2dc8cbc-…` and `ee1647f5-…`)

## Parent property semantics

The plugin (`GenericAssetCreationService.inheritParentContext`) auto-detects the parent class:

- Parent is `ems__Project` → writes `ems__Effort_parent: [[<project>]]`
- Parent is `ems__Area` → writes `ems__Effort_area: [[<area>]]`

No `targetValue` override is needed in the grounding for the standard flow. Starter-kit consumers that want to force a specific parent property can pass `userInput.parentProperty` via `exocmd__Grounding_targetValue` on a custom grounding wired through `4919afb1`'s sibling.
