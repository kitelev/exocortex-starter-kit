# Set Parent → Task binding

Binds the «Set Parent» command (`2d57794e`, cliName `set-parent`) to all `ems__Task` instances —
inline, `maintenance` group, order **216**: right after «Set Ontology» (`215`), its closest
sibling by mechanism (an `assetRef` picker that mutates one object-property), and before
«Rename to UID» (`220`).

Founder decision 2026-09-16 (interview, question 2: «Кнопки с выпадающим списком», ticket
`45dc1514`): the button appears with this binding; the candidate dropdown (`ems__Task ∪
ems__Project` via the class hierarchy, `targetClassUid` in the grounding schema) is a separate
code ticket under `bbac67ce`. Until then the picker falls back to a text field. The command
carries **no precondition**, so the button is visible on every `ems__Task`.
