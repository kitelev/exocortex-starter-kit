Dynamic command that sets `ems__Effort_parent` on the target asset to link it under a parent project or task.

- **Grounding**: Calls `updateProperty` to set `ems__Effort_parent` to user-selected asset
- **Icon**: link (Lucide)
- **Category**: creation
- **Input**: Parent asset reference (asset picker)
- **Precondition**: None (always available)
