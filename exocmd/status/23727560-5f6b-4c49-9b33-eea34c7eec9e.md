# Transition to Doing (status + startTimestamp)

Composite grounding that, in one click:

1. Sets `ems__Effort_status` to `[[ems__EffortStatusDoing]]`
2. Writes the current local timestamp into `ems__Effort_startTimestamp`

Mirrors the semantics of the palette `Exocortex: Start Effort` command
(`TaskStatusService.startEffort`), so users get the same data shape regardless of
whether they trigger the transition via the inline status button or the command palette.

**Requires plugin v15.90.28+** (`$nowLocal` substitution variable used by step 2).

Used by the `Set Status Doing` command (UID `e941b3bb-d375-40d2-b271-e1d71deb014c`).
