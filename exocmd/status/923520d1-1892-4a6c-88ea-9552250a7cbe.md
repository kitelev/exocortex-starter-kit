# Set Status Done

Transitions an effort to the `Done` state in one click — sets `ems__Effort_status`,
**and** writes both `ems__Effort_endTimestamp` and `ems__Effort_resolutionTimestamp`
so the data shape matches the palette `Exocortex: Mark as Done` command.

- **Precondition**: Visible only when asset is NOT in Done status
- **Grounding**: composite — `Set status to Done` + `Set ems__Effort_endTimestamp to $nowLocal` + `Set ems__Effort_resolutionTimestamp to $nowLocal`
- **Icon**: check-circle (Lucide)
- **Category**: status
- **Plugin requirement**: v15.91.0+ (uses `$nowLocal` grounding variable)
