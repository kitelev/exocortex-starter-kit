# Transition to Done (status + end + resolution)

Composite grounding that, in one click:

1. Sets `ems__Effort_status` to `[[ems__EffortStatusDone]]`
2. Writes the current local timestamp into `ems__Effort_endTimestamp`
3. Writes the current local timestamp into `ems__Effort_resolutionTimestamp`

Mirrors the semantics of the palette `Exocortex: Mark as Done` command
(`TaskStatusService.markTaskAsDone`), so users get the same data shape regardless of
whether they trigger the transition via the inline status button or the command palette.

**Requires plugin v15.90.28+** (`$nowLocal` substitution variable used by steps 2 and 3).

Used by the `Set Status Done` command (UID `923520d1-1892-4a6c-88ea-9552250a7cbe`).
