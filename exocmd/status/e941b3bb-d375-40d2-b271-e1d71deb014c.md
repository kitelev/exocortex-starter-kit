# Set Status Doing

Transitions an effort to the `Doing` state in one click — sets `ems__Effort_status`
**and** writes `ems__Effort_startTimestamp` so the data shape matches the palette
`Exocortex: Start Effort` command.

- **Precondition**: Visible only when asset is NOT in Doing status
- **Grounding**: composite — `Set status to Doing` + `Set ems__Effort_startTimestamp to $nowLocal`
- **Icon**: play-circle (Lucide)
- **Category**: status
- **Plugin requirement**: v15.90.28+ (uses `$nowLocal` grounding variable)
