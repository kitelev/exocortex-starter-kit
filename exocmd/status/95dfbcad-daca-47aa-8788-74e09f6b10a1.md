# Set ems__Effort_startTimestamp to $nowLocal

Grounding action that writes the current local timestamp (`YYYY-MM-DDTHH:mm:ss`,
no milliseconds, no timezone suffix) into `ems__Effort_startTimestamp`.

Designed to be chained from a `composite` grounding alongside `Set status to Doing`
so inline `Set Status Doing` button matches the palette `Start Effort` semantics.

**Requires plugin v15.91.0+** (`$nowLocal` substitution variable).
