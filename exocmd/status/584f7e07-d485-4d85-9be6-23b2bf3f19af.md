# Set ems__Effort_endTimestamp to $nowLocal

Grounding action that writes the current local timestamp (`YYYY-MM-DDTHH:mm:ss`,
no milliseconds, no timezone suffix) into `ems__Effort_endTimestamp`.

Designed to be chained from a `composite` grounding alongside `Set status to Done`
so inline `Set Status Done` button matches the palette `Mark Done` semantics.

**Requires plugin v15.91.0+** (`$nowLocal` substitution variable).
